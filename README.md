# NestJS API

A NestJS TypeScript starter application for building efficient and scalable server-side APIs.

## Project setup

```bash
pnpm install
```

## Compile and run the project

```bash
# Development
pnpm run start

# Watch mode
pnpm run start:dev

# Production mode
pnpm run start:prod
```

## Run tests

```bash
# Unit tests
pnpm run test

# End-to-end tests
pnpm run test:e2e

# Test coverage
pnpm run test:cov
```

## Deployment

Before deploying to production, follow the [NestJS deployment documentation](https://docs.nestjs.com/deployment) to help
ensure the application runs efficiently.

To deploy with [NestJS Mau](https://mau.nestjs.com), install the CLI and run:

```bash
pnpm install -g @nestjs/mau
mau deploy
```

## Observability

[NestJS Observe](https://observe.nestjs.com) automatically instruments NestJS applications, providing visibility with
minimal setup.

- **Distributed tracing:** Follow requests across services.
- **Waterfall analysis:** Visualize request execution and identify slow operations.
- **Performance analysis:** Identify bottlenecks and unexpected delays.
- **Metrics:** Track application and infrastructure health.
- **Logging:** Correlate logs with traces.
- **Error tracking:** Investigate errors with surrounding context.
- **SLA monitoring:** Track service-level objectives.
- **Alarms and alerts:** Respond to critical errors and performance degradation.
