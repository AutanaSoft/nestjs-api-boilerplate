# TypeScript General Practices

## Rule Index

- `ts-avoid-any-at-unknown-boundaries` - Validate and narrow unknown input.
- `ts-derive-types-from-runtime-values` - Keep runtime values and types aligned.
- `ts-extract-reusable-object-shapes` - Name meaningful nested domain shapes.
- `ts-use-type-only-imports` - Mark compile-time-only imports explicitly.
- `ts-use-generics-and-utility-types` - Derive transformed types without duplication.

Read the corresponding atomic card in this directory for examples and sources.
