# TypeScript Zod v4 Practices

This skill contains framework-independent Zod 4 validation and shared-contract rules.

## Structure

- `SKILL.md` - Activation and rule index.
- `references/zod-*.md` - Zod API and parsing rule cards.
- `references/contracts-*.md` - Shared-contract boundary rule cards.

## Maintenance

1. Confirm that a proposed rule belongs to Zod 4 or a framework-independent contract boundary.
2. Verify API claims against current official Zod documentation.
3. Create or update an atomic card under `references/`.
4. Use an accepted impact, at most four tags, focused examples, and an official HTTPS source.
5. Update `SKILL.md` and this inventory when the catalog changes.
